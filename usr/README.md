# Salyut-7 Nightmare

A psychological sci-fi horror game atmosphere built in Flutter. Explore an abandoned 1985 Soviet space station inspired by Salyut-7. The environment is a frozen cylindrical orbital station where emergency lights have long failed, leaving you to navigate dark corridors with only a flashlight.

The atmosphere focuses on tension, isolation, and a feeling of being watched. A mysterious reptilian creature stalks the shadows, and you can occasionally see its glowing eyes in the darkness. Access old Soviet computer terminals with green monochrome text to read corrupted logs and uncover the station's dark secrets.

## Features
- **Flashlight Exploration:** Interactive flashlight mask simulating limited visibility in dark environments.
- **Tense Atmosphere:** Dark, frozen space station background with noise and scanline overlays.
- **Psychological Horror:** Occasional appearances of mysterious glowing eyes that vanish quickly, building tension without cheap jumpscares.
- **Soviet Terminal Mini-Game:** Access a retro 1980s-style computer terminal with authentic green CRT text, corrupted log files, and scanline effects.
- **Responsive Layout:** Adaptive design that scales across mobile, tablet, and desktop formats while preserving the tense atmosphere.

## Tech Stack
- Flutter (Dart)
- Cross-platform support (Web, iOS, Android, Desktop)

## Getting Started

1. Ensure you have Flutter installed.
2. Clone the repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the game atmosphere on your preferred device.
